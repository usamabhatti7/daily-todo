# Security policy

Daily To-Do stores tasks locally and has no accounts. The Windows app makes no network requests. The Android app makes one only when you tap **Updates**: an HTTPS request to the GitHub releases API for this repository, and it only accepts download links that point into this repository's releases.

## Reporting a vulnerability
Please use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not post details in a public issue.

## Supported versions
Only the latest release receives security fixes.
